# 商务标模板写作工作台

用户引用本技能并要求“生成界面”“商务标写作”或继续修改已有工作台时，交付能实际操作的页面及其运行所需文件。只要求编写或调整技能时，修改技能资源即可，不额外启动应用或改造宿主。

本目录提供生成规则和数据约定，没有预置可启动的工作台或完整 DOCX 处理服务。生成任务中需要实现并验证缺少的能力；仅加载技能或通过 Markdown 校验不代表业务功能可用。

## 核心约束

- 工作流固定为：上传 → 左侧原文 HTML、右侧模板目录与范围调整 → 底部居中“下一步” → 填充内容弹框 → 弹框右下角“一键替换” → 左侧模板目录、右侧当前模板结果 → 右上角“导出”下拉菜单。
- DOCX 原件是版式和位置的基准。先建立原件位置索引，再绑定 HTML，不能用 HTML 重新排版生成 Word 来冒充保真截取。
- 用户调整的范围是后续截取、替换、预览和导出的唯一有效范围；选区不只是视觉高亮。
- 保留源文件模板层级，支持拖拽排序、新增同级/子级、重命名、删除、展开/收起、撤销/恢复。名称和序号不是节点身份。
- AI 仅根据本轮用户提供的填充信息生成定位明确的内容补丁；不编造公司信息、资质、业绩、报价或签章。
- 所有会话数据、页面源码、转换结果、缓存、日志和导出文件写入 `temp` 内的独立会话目录。技能本身及维护用参考文档留在 `.cursor/skills/business-bid-writer/`。

## 开始执行

1. 读取项目 `AGENTS.md`，检查已有页面、组件及本轮真实附件。复用本轮工作台状态，避免跟进修改时重新解析、丢失用户范围或目录排序。
2. 读取 [交互流程](references/interaction-flow.md) 和 [会话数据与动作约定](references/session-contract.md)。实现 DOCX 处理前再读取 [原文映射与保真导出](references/docx-fidelity.md)。
3. 创建 `temp/<sessionId>/business-bid/`；若宿主已指定会话 temp，则使用 `<宿主会话 temp>/business-bid/`，不再嵌套第二个 temp。所有文件路径相对此工作目录解析，禁止通过用户输入的名称越过工作目录。
4. 默认支持 DOCX。用户尚未上传时先显示可用的上传空状态，不伪造已解析结果，也不要求用户先在聊天中上传才能生成上传页面。用户已有附件时直接接入。对 DOC/PDF 等格式先检测转换能力；不能保证可编辑性及映射时明确标注，不把图片版 Word 当作可替换模板。
5. 根据本地实际能力选择可交互实现方式；读取 [运行与验收](references/runtime-and-validation.md)。落实上传、文件处理、状态落盘、AI 调用和下载通路，再生成页面。不能臆造 OpenUI 组件、IPC、API 或依靠浏览器直接写任意磁盘目录。

## 生成与续接

- UI 使用中文，原文纸张区域保留文档版式，目录区域使用紧凑树形列表。只借鉴 [参考页面记录](references/page-reference.md) 中已观察到的交互；用户指定流程优先于参考站点。模板名称来自本轮文档，不固定套用参考项目的模板清单。
- 分析全文，区分目录中的标题副本与模板正文，识别真实表单及填写说明。对不确定的起止边界标为待调整，让用户在左侧核对。
- 先实现模板节点、原件锚点和状态模型，再实现双栏、目录操作、框选、弹框和结果页。关键操作必须调用实际处理逻辑并有加载、成功、失败和重试状态。
- 首次替换默认处理全部有效模板；`activeTemplateId` 只控制预览，点击历史不决定导出集合。进入结果页后延续最后预览的模板，用户可切换任意模板。允许显式排除某模板，并在导出前显示实际数量。
- 调整范围后递增该模板范围版本，旧截取文件、补丁和结果立即过期；重新截取后再替换。只调整目录顺序不重新解析原件，但必须使 ZIP 顺序和合并顺序同步更新。
- 保存用户输入、目录编辑、范围和处理结果；刷新或返回上一步可恢复。切换另一份源文件要建立新的源版本，不把旧锚点套用到新文件。

## 完成标准

按 [运行与验收](references/runtime-and-validation.md) 检查完整操作链及真实文件内容。仅 UI 演示不能宣称上传解析、AI 替换和保真导出已完成；未接通的能力明确说明，不能用延时、弹提示或伪下载代替。

用户要求“验证技能是否符合需求”时，分别报告需求覆盖、已有处理能力的实测、完整页面验收结果。没有生成并操作真实页面时，页面验收标为未验证；局部截取脚本通过不能代替 HTML 映射、AI 替换或合并导出的验收。按验收任务范围推进，不为得到全绿结果而临时编写一套简化业务实现或修改线上数据。

交付可打开的页面/入口、会话目录与已生成产物的实际路径，并简要报告验证范围及限制。生成页面时如果改变宿主模块边界、数据流、持久化或接口，应在本轮更新 `docs/architecture/` 对应 Mermaid 图；只维护技能文字而未改变运行架构时无需新增架构图。
