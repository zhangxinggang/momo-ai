# 交互流程

## 上传与解析

初始页面有单文件上传/拖入区域、支持格式说明和处理状态。上传后依次显示“读取文件”“转换预览”“识别模板”。保留原始文件名，仅在内部使用安全文件名。转换失败能重试，换文件不覆盖原件。

解析对象是“投标文件格式/投标文件模板/附件表单”等真实正文。覆盖正文表格、签章区、附录和模板说明，不把全文每个标题都当模板，不将目录中的一行标题当完整模板。保留原目录层级；无层级则显示平铺列表。纯组织目录用 folder，有可截取正文的节点用 template，两者不可混淆。

## 范围调整页

桌面默认左侧约 65% 为原文 HTML，右侧约 35% 为模板树；分栏可拖动，两侧独立滚动。底部操作条不遮挡文档，正中显示“下一步”。窗口窄时允许调整面板宽度或切换面板，操作仍可访问。

### 左侧 HTML

- 展示由原件生成的预览，保留字体、字号、段落、表格、空白、图片与页面尺寸。浏览器预览与 Word 分页可能有差异，需实际核验。
- 点击右侧模板后默认只展示该模板的当前有效范围，显示“起”“止”边界和模板名；不能仅在整篇文档中滚动到标题便算完成。进入范围调整时可切换到“全文”，显示相邻原文以扩展边界，并框出当前范围；过滤预览不能改变源位置编号。
- 点击已选模板或“调整范围”进入编辑。拖动起止手柄、点击块后“设为起点/设为终点”，以及键盘/按钮逐块微调，三者写入同一份范围。默认吸附完整段落、整表或完整内容控件。
- 框选可跨页，滚动、缩放和窗口变化后重新计算框线；坐标只作展示，持久化的是原件锚点。起点大于终点、空范围或不存在的锚点不能保存。
- 草稿范围可即时预览，提供“应用范围”“取消”“恢复识别范围”。切换模板时先保存有效草稿；无效草稿明确提示，不静默遗失。离开调整模式后显示已应用范围。
- 选区跨入其他模板时显示重叠提示及两端上下文，不悄悄截断或移动相邻模板。最终导出有重叠会重复内容，须让用户明确选择保留或调整。

### 右侧目录

| 操作 | 行为 |
| --- | --- |
| 点击模板 | 保存当前有效编辑，设置 activeTemplateId，定位该模板范围；点击 folder 只展开/收起 |
| 拖拽 | 显示插入线；支持同级前后排序及合理的跨层级移动，不能拖入自身或后代 |
| 新增同级/子级 | 在指定位置创建稳定 ID；可新增分组或模板，新模板显示“待绑定原文范围” |
| 重命名 | 只改目录显示名，不擅改源文标题；拒绝空名，处理同级重名 |
| 删除 | 移除会话节点；有子节点时说明连带范围，支持撤销；不修改上传原件 |
| 展开全部/收起全部 | 仅更新界面展开状态 |
| 撤销/恢复 | 恢复目录和选区编辑，相关生成文件按恢复后的版本重新判断有效性 |
| 重新识别 | 提醒会影响手工目录/边界并保留可回退快照，不能自动覆盖当前编辑 |

有正文又有子项时可使用 template 节点挂子节点，但要检测父子内容重复。更推荐分离分组节点和模板节点；不能为简化树而丢弃父节点正文。

## “下一步”与填充弹框

点击底部正中“下一步”时，先验证至少一个纳入导出的模板且每个模板范围有效。无来源的新模板、未解决边界或正在转换时，提示具体节点及原因。

通过后弹出“填写模板填充内容”：包含支持自然语言粘贴的多行输入，可附加从真实模板识别的字段表，如单位名称、项目名称、法定代表人、日期等。字段随模板生成，不要求所有项目填写同一清单。已有值可编辑，关闭弹框保留草稿。

弹框底部右下角主按钮为“一键替换”，旁边为“取消”。输入全空时禁止执行。页面可展示识别出的字段与用户原始内容，歧义项标出，不能默默将同名人填入不同角色。

## 替换结果页

点击“一键替换”后切换为左侧模板树、右侧当前模板结果。生成期间展示逐项进度和禁用中的导出；不因页面切换就显示成功。

- 左侧沿用同一目录及稳定 ID，显示待处理/生成中/完成/失败/待补充状态。
- 右侧展示当前选中模板的真实生成文件预览，范围以用户最后应用的选区为准。若进入结果页时无选中模板，选择第一个有效模板；保留切换记录，不能只展示标题或替换 JSON。
- 可查看填充前后差异和未填项；“待补充”表示原文保留，不能装成已成功匹配。范围过期、处理失败的模板不能被算作完成。
- 部分失败可逐项重试，已成功且版本未变的模板无需重跑。重复点击不重复提交同一批任务。
- 支持返回范围页和修改填充内容；原件不变。改范围使对应结果过期，改填充值使受影响结果过期。迟到的旧任务不能覆盖新版本。

## 导出

结果页右上角固定“导出”下拉，仅包含主需求的两个选项：

1. **导出 ZIP**：将当前纳入集合的所有有效 DOCX 打包，按目录路径和当前顺序命名。只组织用的 folder 不生成空 DOCX。同名安全去重，压缩包名如“商务标模板.zip”。
2. **合并导出**：以相同集合和树的深度优先顺序合并为“商务标合并.docx”，保留各模板的节、版式、图片和编号；不能拼 HTML 或拼 ZIP 字节。

两个导出使用同一状态快照。集合有失败、过期或未绑定模板时阻止“全部导出”并定位问题；若支持部分导出，必须明确让用户选择并展示排除列表。未填字段但用户允许保留的有效模板可导出，界面提示剩余项数量。不要把点击过的模板集合当作“所有文件”。
